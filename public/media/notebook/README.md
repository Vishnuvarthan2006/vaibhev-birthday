# Notebook Photographs

Place photos attached to individual notebook entries here.

### Recommended structure:
You can drop images directly or group them by friend folder:
- `/media/notebook/friend-1/photo1.jpg`
- `/media/notebook/friend-2/photo1.jpg`
- ...
- `/media/notebook/friend-9/photo1.jpg`

Reference these paths in `src/data/notebookData.ts`.
Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
